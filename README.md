# Jackkwest UAE End-of-Service Calculator

A WordPress plugin for estimating UAE end-of-service gratuity based on an employee's salary and length of service.

## About

Jackkwest UAE End-of-Service Calculator provides a simple way to estimate gratuity amounts for employees working in the UAE.

The plugin is designed to make UAE gratuity calculations easier to understand and use.

## Features

- UAE end-of-service gratuity calculation
- Simple calculation interface
- Salary and service-period based estimation
- WordPress shortcode support
- Lightweight and easy to use

## Online Calculator

For an online UAE gratuity calculation tool and additional information, visit:

https://thegratuitycalculatoruae.com/

## WordPress Shortcode

The calculator can be displayed using the following shortcode:

[gratuity_calculator_uae]

## Installation

1. Download the plugin package.
2. Log in to your WordPress dashboard.
3. Go to **Plugins → Add New → Upload Plugin**.
4. Upload the plugin ZIP file.
5. Install and activate the plugin.
6. Add the shortcode to any page or post where you want the calculator to appear.

## Disclaimer

This plugin provides an estimate for informational purposes. Actual end-of-service benefits may depend on employment circumstances and applicable UAE regulations. Users should verify calculations against the latest applicable UAE requirements.
